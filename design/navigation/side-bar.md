# Side bar

The navigation sidebar provides fast, always-visible module switching with attention indicators, using icon-only design to save space and eliminate sluggish expansion animations.

Functionality:

* module switching
* attention indicators

<figure><img src="../.gitbook/assets/image (8).png" alt=""><figcaption></figcaption></figure>

## Principles

### Keep it simple

* No state management (expanded vs collapsed)

### Intuitive for beginners

* Common pattern
* Badges clearly indicate where attention is needed

### Powerful for experts

* No animation delays
* Visual scan is fast
