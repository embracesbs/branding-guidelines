# Top bar

## The problem

Not enough screen real estate for future features. Patterns were unfamiliar. Search was 'hidden'.

## The decision

Introduce a **persistent top bar** for Suite-level functions, following familiar patterns.

Introduce a **split between functionalities**: top bar for Suite-level, side bar for module-level.

## Principles

### Keep it simple

* Clear visual separation: Suite functions (top bar) vs module functions (side bar)

### Intuitive for beginners

* Follows Jakob's Law: borrows patterns from well-known applications out there (Microsoft, Google, Asana, Zendesk, HubSpot).
* Users expect search in top bar
* Users expect app launcher in top-left corner

### Powerful for experts

* Keyboard shortcut access for Search
* Status visible but unobstrusive
