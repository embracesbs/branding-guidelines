# Panels

## The main panels

<figure><img src="../.gitbook/assets/afbeelding (22).png" alt=""><figcaption><p>The main three-pane structure of the Suite. An overlay is highlighted in blue.</p></figcaption></figure>

### List panel

* Goal: to select
* Content: selectable items (colleagues, groups, conversations, tickets, tasks...)&#x20;

<figure><img src="../.gitbook/assets/afbeelding (25).png" alt=""><figcaption></figcaption></figure>

### Main panel (details)

* Goal: to handle primary action
* Content: primary content (conversations, ticket details, email thread...)

<figure><img src="../.gitbook/assets/afbeelding (26).png" alt=""><figcaption></figcaption></figure>

### Context panel

* Goal: to aid
* Content: secondary content (colleague card, relation card, contract information...)

<figure><img src="../.gitbook/assets/afbeelding (27).png" alt=""><figcaption></figcaption></figure>

## Four column variant

Some modules entail an extra collapsible **folder column** to help with the initial list panel 'to select' goal.

* Folders > List > Main > Context
* Folder column can be collapsed or expanded

<figure><img src="../.gitbook/assets/afbeelding (28).png" alt=""><figcaption></figcaption></figure>

## Use cases

### Example usage

* Social: colleagues, documents, pages
* CRM: chat, dossiers, tasks

### Exclusions

* Editing modules (page editor, conversation editor, article editor)
* Portal-based modules (dashboard, group dashboard)
* Any module focused on creation rather than other main actions
